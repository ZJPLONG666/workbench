常见报错对照
404：请求到达了服务器，但模型名是空的或不存在 → 检查「生图模型名称」
401：Key 错了、过期或复制带了空格 → 重新粘贴
403：无权限，OpenAI 的 gpt-image-1 需要先完成组织验证
429：余额不足或请求太频繁
Failed to fetch：网络不通或被 CORS 拦截 → 用下面的本地中转
400 + response_format：该模型不支持此参数 → 响应格式改成「自动」
跨域说明：浏览器直连部分国内接口会被 CORS 拦截。解决办法是填你自己的中转/代理地址（如本地 http://127.0.0.1:3000/v1）。
密钥：保存在本机浏览器 localStorage，不会上传到任何第三方，但共用电脑请勿保存。

豆包（火山方舟）去哪找 · 三步走

第 1 步 · 进控制台
console.volcengine.com/ark （左侧菜单「火山方舟」→ 需先手机号注册 + 实名认证）

第 2 步 · 拿 API Key
左侧菜单「API Key 管理」→ 创建新密钥 → 立即复制保存（只展示一次）
直达：API Key 管理页

第 3 步 · 开通模型 + 复制模型 ID
左侧菜单「开通管理」→ 搜索 Doubao-Seedream（文生图）与 Doubao-Seed-1.6-Vision（读图）→ 点「开通」
开通后在同一页复制完整模型 ID（形如 doubao-seedream-5-0-260128，必须带日期后缀）

接口地址是固定的，不用查：
https://ark.cn-beijing.volces.com/api/v3
请求路径：读图用 /chat/completions，出图用 /images/generations

注意：火山方舟不是「有 Key 就能调所有模型」，每个模型要单独开通。没开通报 ModelNotOpen，模型不存在报 InvalidEndpointOrModel.NotFound，两者都长得像 404，但处理方式不同。

模型可用性探测（找不到可用模型时用这个）

逐个测试候选模型 ID，直接告诉你哪个能用、哪个没开通。读图探测不花钱；出图探测会真实生成图片（约几分钱一张）。

反推提示词的固定要求

系统内置了统一的反推指令，输出必须满足：
· 完整描述图中的主体、构图、场景、光线、材质、色彩、氛围、风格
· 纯中文，一段式自然语言，可直接粘进生图工具
· 不要前言解释、不要标题、不要分点、不要小标题、不要任何英文
· 长度控制在 300-500 字
