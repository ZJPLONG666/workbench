# 曾生夫妻创业工作台

夫妻二人（曾生 + 老婆）创业工作/生活用的定制化智能工作台。单文件 HTML 应用，纯前端、数据存浏览器本地，支持多设备云端同步与飞书日历提醒。

## 访问地址
- 永久链接（GitHub Pages）：`https://<你的GitHub用户名>.github.io/workbench/`
- 多设备用法：每台设备用浏览器打开上面的链接 → 在「云端同步」里输入同一个**同步码** → 数据自动互通。

## 功能模块
- **任务看板**：可拖拽、可编辑的任务板（右下角保存按钮）。
- **日历/日程**：与任务联动，任务可设「具体到几点的截止时间」。
- **数据看板**：销量/销售额增长曲线（Chart.js）。
- **账号管理**：2 主账号 + 3 子账号笔记追踪。
- **WorkBuddy 悬浮助手**：底部圆形按钮 + 半透明弹窗。
- **提醒设置**：到点提醒（前端蜂鸣/系统通知）+ 飞书日历同步。

## 提醒（飞书日历）
带截止时间的任务会同步进飞书日历「工作台任务」，到点飞书弹通知。
手动同步脚本见 `feishu_sync.py`（需先在飞书客户端授权 `lark-cli`）：

```bash
python feishu_sync.py --json-file <工作台导出的全量备份.json>
# 或读取云端同步码
python feishu_sync.py --sync-code <你的同步码>
```

## 部署说明
本仓库即 GitHub Pages 站点根目录：`index.html` 为入口，`index.html` 通过 Tailwind / Chart.js CDN 加载样式与图表。
推送 `main` 分支并启用 Pages 后即生效。`.nojekyll` 用于跳过 Jekyll 处理。
