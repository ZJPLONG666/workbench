☁️ 云端同步

在两台设备上输入同一个同步码，数据就会自动互通（每次保存 + 每15秒自动同步）。首次使用：留空点「连接」，系统会自动生成一个同步码，把这个码告诉老婆即可。

提示：同步码等于数据钥匙，请只发给你老婆，不要外传。

📲 添加到主屏幕（像 App 一样用）

iPhone / iPad：Safari 打开工作台网址 → 底部分享按钮 →「添加到主屏幕」

安卓手机：Chrome 打开网址 → 右上角 ⋮ 菜单 →「添加到主屏幕」

Windows 电脑：Edge / Chrome 打开网址 → 地址栏右侧「安装应用」图标，或收藏网址

💾 本地双备份（不依赖云端）

云端工作空间偶尔会休眠（之前就遇到过）。本地双备份让你们断网/云端挂了也能用，数据永远不会丢：

① 文件副本（离线可用）
把工作台 HTML 存到电脑桌面 / 手机，双击即可打开，数据存在本机浏览器。
② 数据文件（可外存）
一键导出整库 .json 备份，存到微信文件助手 / U盘 / 网盘，随时导入恢复。

建议：每周导出一次 .json 备份；换新手机/电脑时，先导入备份再连同步码。
